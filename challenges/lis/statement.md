# Longest Increasing Subsequence

Given a sequence of `n` integers, compute the length of its longest **strictly
increasing** subsequence.

## Input

- First line: one integer `n`.
- Second line: `n` integers `a_1 a_2 ... a_n` (space separated).

## Output

- One line with a single integer: the length of the longest strictly increasing
  subsequence.

## Constraints

- `1 <= n <= 10^5`
- `-10^9 <= a_i <= 10^9`

## Example

```
Input:
7
1 3 2 4 7 5 6

Output:
5
```
